# beating-heart ❤️

李峋同款跳动爱心（《点燃我，温暖你》）——原版为 Python/pygame 粒子爱心，手机跑不了 Python，
本仓库是**同款参数方程算法的网页移植版**，手机浏览器点开即看，无需安装任何东西。

**在线演示：https://www7398.github.io/beating-heart/**

## 自定义中间文字

在链接后面加 `?t=` 参数即可，例如：

```
https://www7398.github.io/beating-heart/?t=小文文
```

- 不加参数默认显示 `I ❤ You`
- 加 `?t=`（留空）则不显示文字
- 最多 14 个字

## 操作

- 点击屏幕进入全屏（更沉浸）
- 双峰"咚-咚"心跳 + 粒子闪烁 + 光晕外扩，均为原版效果

## 本地运行

`index.html` 是零依赖单文件，双击即可在浏览器打开，也可直接通过 QQ/微信发送给对方。
